# 高洁 Allen Gao · 个人网站

一个单页静态站，部署在 GitHub Pages：https://g19930311-lang.github.io/allen-gao-portfolio/

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面本体：结构 + 样式 + 交互，全部在这一个文件里 |
| `site-data.js` | 全站文案与数据（案例、能力、笔记、联系方式…），改这里最安全 |
| `assets/` | 图片与简历：头像、生活照、简历 PDF |
| `og-image.png` | 分享到微信/社交平台时显示的预览图（1200×630） |
| `favicon.svg` | 浏览器标签页图标 |
| `robots.txt` / `sitemap.xml` | 给搜索引擎看的 |

## 改内容的两条路

**路线 A：用网站自带的后台（推荐，不用碰代码）**

1. 打开网站 → 页脚点「管理后台」（或连点左上角 Logo 三次）
2. 默认密码 `allen2024`，进去后先到「安全」里改掉
3. 改完在「发布 / 备份」里填 GitHub Token，点「一键发布」

> 后台的改动默认只存在你自己的浏览器里，**必须点发布**才会对所有人可见。

**路线 B：直接改 `site-data.js`**

用记事本或 VS Code 打开 `site-data.js`，改引号里的文字，别动引号和逗号。改完提交到仓库即可。

## 新增内容（2026-10 改版）

- **笔记栏目**：在 `site-data.js` 的 `notes` 数组里加一条，就会出现在首页「笔记」区
  ```js
  { id: 'n4', date: '2026.11', tag: '内容方法', title: '标题', excerpt: '摘要', url: '文章链接（可留空）' }
  ```
- **案例详情**：每个作品除 `desc` 外，还支持 `challenge`（当时的处境）、`actions`（我做了什么）、`results`（结果）、`link`（外链）。点开作品卡片就是完整的案例页。
- **状态徽章**：`status.text` 控制右上角那句「可接品牌内容项目」，`status.available: false` 会变成灰点。
- **首屏照片**：`about.avatar` 上传后会同时出现在首屏和「关于我」。

## 本地预览

双击 `index.html` 即可，不需要装任何东西。
